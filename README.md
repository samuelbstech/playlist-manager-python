# 🎵 Playlist Manager

Sistema interativo de gerenciamento de playlists musicais desenvolvido em Python via terminal. Permite organizar músicas, listar detalhes e calcular métricas de duração.

## 🚀 Funcionalidades

- **Cadastrar Músicas:** Adiciona faixas informando título, artista e duração (em minutos).
- **Remover por Nome:** Busca e remove faixas pelo título (com tratamento de maiúsculas/minúsculas).
- **Listagem Completa:** Exibe todas as faixas cadastradas com numeração e contador total.
- **Cálculo de Duração:** Soma dinamicamente o tempo total de reprodução da playlist.

## 🛠️ Tecnologias Utilizadas

- **Python 3** (Estruturas de Dados com Listas e Dicionários)

## 💻 Como Executar

```bash
python main.py
